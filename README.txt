AGROCLIMA - VERSION LISTA PARA GITHUB PAGES

1. En tu repositorio, elimina/reemplaza los archivos anteriores.
2. Sube index.html y la carpeta src completa a la raiz del repositorio.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Espera a que GitHub marque el deployment como completado y abre la URL publicada.

No requiere npm, Vite ni compilacion local.
